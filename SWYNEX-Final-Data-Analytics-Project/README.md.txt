# SWYNEX Final Data Analytics Project

This project combines my SWYNEX internship work in data cleaning, exploratory data analysis (EDA), and a Power BI dashboard using the Sample Superstore dataset.

## Problem Statement
Explore sales and profit across time, products, regions, customers, and discount levels to find useful business insights.

## Dataset
- **Name:** Sample Superstore sales dataset
- **Records:** 9,994 rows and 21 columns
- **Period:** January 2014 to December 2017
- **Purpose:** Educational project

## Project Work

### Task 1: Data Cleaning
I used Python and pandas to check duplicates, clean text, format dates, validate numeric values, and prepare the dataset for analysis. The final dataset has 9,994 rows and 21 columns.

### Task 2: Exploratory Data Analysis
The analysis explored sales and profit by category, sub-category, region, customer, and discount.

**Key findings:**
- Total sales: **$2,297,200.86**
- Total profit: **$286,397.02**
- Technology had the highest category sales and profit.
- West was the most profitable region; Central was the least profitable.
- Tables had the largest sub-category loss.
- Sales in 2017 were 20.4% higher than in 2016.

### Task 3: Power BI Dashboard
The interactive dashboard is included in the `task-3-dashboard` folder. Open the `.pbix` file using Power BI Desktop.

## Business Insights
- Review high discounts and their effect on profit.
- Investigate losses in Tables and lower profit in Central.
- Study the strong results in Technology and West to understand what may be driving them.

## Tools Used
Python, pandas, CSV, Matplotlib, and Power BI.
